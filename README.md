## Installation

Clone repository:

```bash
git clone https://github.com/username/repository-name.git
```

Masuk ke folder project:

```bash
cd repository-name
```

Install dependencies:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Buka di browser:

```
http://localhost:3000
```
